Data Processing Agreement

Effective date: 21 June 2026  |  GDPR Article 28 compliant

Key fact: OpsManifest is designed to process as little personal data as possible. Build data (infrastructure configurations, project plans, risk logs) is stored locally in your browser by default and never leaves your device unless you explicitly enable cloud sync. The primary personal data processed is your email address, used only for authentication and cloud sync.

1. Definitions

  • Controller: The Customer organisation that determines the purposes and means of processing personal data.
  • Processor: Flourishing, the provider of OpsManifest, acting on the Controller's instructions.
  • Personal Data: Any information relating to an identified or identifiable natural person as defined under applicable data protection law (including GDPR, UK GDPR, and the Indian Digital Personal Data Protection Act 2023).
  • Processing: Any operation performed on Personal Data, including collection, storage, use, disclosure, and deletion.

3. Data Minimisation by Design

  • Local-first architecture: All build data defaults to browser-local storage (IndexedDB). No build data is transmitted to any server unless the user explicitly enables cloud sync.
  • No tracking: OpsManifest does not use advertising trackers, third-party analytics, or cookies for profiling.
  • Guest mode: Users can run the full core workflow without creating an account or providing any personal data.
  • AI is optional: OpsMentor AI features are opt-in and clearly labelled. Disabling them eliminates all AI-related data transmission.

5. Data Retention and Deletion

  • Local data: Stored in the user's browser until the user clears their browser data or requests deletion. The Controller (or end user) can delete local data at any time through browser settings.
  • Cloud sync data (Pro+): Retained for the duration of the subscription plus 30 days after termination, after which it is permanently deleted from Firebase.
  • Right to erasure: The Controller may request deletion of all cloud-stored data by emailing sriram.c76@gmail.com. Deletion will be completed within 30 days.
  • AI/TTS data: Not retained beyond the duration of the request. Groq and Azure do not store input data after processing.

6. Security Measures

  • HTTPS enforced on all connections (TLS 1.2 minimum, Cloudflare managed)
  • Firebase Firestore security rules restrict data access strictly to the authenticated account owner
  • No API keys are exposed in the browser bundle — all third-party API calls go through a Cloudflare Worker proxy
  • Content Security Policy headers restrict script and connection sources
  • No admin access to individual user build data without explicit consent

7. Data Subject Rights

The Processor will assist the Controller in responding to data subject requests (access, rectification, erasure, portability, restriction, objection) within the timescales required by applicable law. To submit a data subject request, contact sriram.c76@gmail.com.

8. Data Breach Notification

In the event of a personal data breach affecting data processed under this Agreement, the Processor will notify the Controller without undue delay and in any event within 72 hours of becoming aware of the breach. Notification will include: the nature of the breach, categories and approximate number of records affected, likely consequences, and measures taken or proposed to address the breach.

9. International Data Transfers

Some sub-processors (Firebase, Groq, Azure, Cloudflare) are based in the United States. Where personal data is transferred outside the EEA or UK, the Processor relies on: (a) Standard Contractual Clauses (SCCs) as incorporated in the sub-processors' terms; or (b) the sub-processor's certification under an applicable adequacy framework. Details are available on request.

10. Audit Rights

The Controller may request, no more than once per year, a written summary of the Processor's data protection practices and sub-processor list. The Processor will respond within 30 days. Physical audits require prior written agreement and are subject to confidentiality obligations.
