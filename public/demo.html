Architecture & Data Security

Your data input, how it is processed, and where it is stored

✏️
What you enter
Structured project fields: hardware, OS, database, app tier, go-live date, design decisions, and RAID entries. No passwords, no server hostnames, no credentials, no PII - ever.
No PII collected No credentials ever
⚡
How it is processed
All RTM checks, coherence rules, and task calculations run locally in your browser. When OpsMentor answers a question, only your stack summary passes through a Cloudflare Worker proxy - no documents, no raw text, no server names.
All logic runs locally AI sees stack summary only
💾
Where it is stored
Free: builds live in your browser's IndexedDB - on your device only. Pro+: optional encrypted sync to Firebase Firestore. You own your data, can export it any time, and can delete it on demand. Cloud sync is always an explicit opt-in.
Local-first by default Encrypted in transit (Pro+) You own your data
